# 自绘控件无障碍审计

2026-11-08，PR #409，DESK-01。基线 `df94e3b2`。

## 范围与判据

检查 `widgets/ui`、`widgets/glass`、shell，以及 screens/widgets 中的
`GestureDetector`、`InkWell`、`Semantics`、`ExcludeSemantics` 和自绘颜色/分隔条入口。
逐类区分独立动作、容器内的独立子控件、媒体画布手势及已有 Material 控件；不能把所有
GestureDetector 机械替换成按钮，否则网格会新增数百个 Tab 入口，画布还会吞掉内部操作。

本轮针对名称、角色、选中/禁用/展开状态、语义动作、Tab/Enter/Space、可见焦点和重复朗读。
参考维护中的 UI 规格与本地真实渲染；未取得原始设计稿。保留尺寸、暖石灰表面、配对强调色、
玻璃及动效。新焦点轮廓在现有控件内部绘制，不改变测量尺寸或增加玻璃层。

## 已处理

| 控件/入口 | 发现 | 处理 |
|---|---|---|
| GlassSegmented / GlassIconButton / GlassFab | 手势可点但没有 Tab/键盘激活；标签与 tooltip 重复 | 共用 AppActionTarget，提供单一名称/动作/焦点、禁用状态与焦点轮廓；分段重复选择幂等 |
| Shell 导航、手机 dock、Windows caption buttons | 自绘手势按钮缺少键盘入口 | 同一 action target；保留导航快捷键 hint，徽标单列 value；不修改 Snap 原生协议 |
| 浏览器视图切换、类别筛选、选择栏主动作 | 已选项变成无动作项，其他动作依赖鼠标 | 已选项仍可聚焦，重复激活不应用筛选；原布局和滚动保留 |
| 工作台工具菜单、助手/裁剪/蒙版保存、模型/费用组保存、参考图移除 | 独立手势入口不能键盘激活 | 复用 action target；保持原有忙碌/禁用回调边界 |
| AppIconButton、预览标准图标按钮 | tooltip 字段不等于独立语义名称 | AppControlLabel 合并名称与可操作节点；显式 tooltip 排除重复语义，视觉提示保留 |
| AppSettingRow / AppToggleRow、Markdown 与对比器开关 | 标签与 Switch 分离，或外层与 Switch 重复焦点 | 单一 Switch 合并标签；footer 独立。通用 trailing 可能包含多个操作，只对 AppSwitch 合并整行 |
| 色相条/色轮、主题色预设、渠道/分类色块、搜索选项 | 缺少名称、选中态或调节动作 | 色相 5° 循环键盘/语义增减；颜色码命名色块；主题色/选项报告选中状态；主题预览内部装饰排除语义 |
| PanelResizer、执行日志高度拖柄 | 只有拖动入口 | Tab 进入后沿轴方向键每次移动 20px，沿用原有限制与持久化回调；四语言读屏自定义方向动作 |
| 目录展开、移除、折叠后的目录导航 | 子动作缺少焦点/展开状态，隐藏操作不可见 | 独立具名动作；展开状态；键盘进入行时显示操作；目录复选框使用路径名称 |
| 任务浮动胶囊 | 展开依赖点击整块，隐藏时仍可能有键盘入口 | 头部独立展开动作；隐藏时排除焦点；保留鼠标拖移和内部“查看全部”动作 |
| 媒体预览与视频控制条 | 整个预览及视频控制条被 ExcludeSemantics 隐藏 | 恢复语义边界；关闭/保存/分享/翻页、缩略图及播放/静音可识别；键盘聚焦显示控制条，读屏模式不自动隐藏视频控制；关闭后恢复文件区焦点 |

名称与动作必须落在同一语义节点。单个复合按钮可用 MergeSemantics；一个容器含多个独立
操作时不得整体强制合并。AppActionTarget 仅包自绘单动作，不包 TextField/Switch 或整个网格。

## 保留的实现与边界

- AppButton、AppSwitch、Material 输入/菜单继续使用框架的键盘/状态实现；AppMenuAnchor 的
  局部语义边界保留，不能为减少节点而移除。
- 文件卡/画廊卡继续由 DESK-02 的单 pane 和逻辑活动项导航，不给每张卡新增节点。
  下载器卡已有名称、选中状态及语义点击；本轮未为下载器新建网格方向键引擎。
- 模型参数滑杆已有语义增减和键盘步进，保留原有范围/格式器。色相与布局分隔条不是模型参数。
- 图像平移缩放、蒙版笔划、裁剪几何、图层命中、窗口拖移和重排拖拽属于连续空间操作。
  本轮审计了它们与子控件的边界，不将它们伪装成无名按钮，也不声称已提供所有画布操作的
  无鼠标替代。图层已有列表/显隐入口；更完整空间编辑工作流须另行定义和验收。
- 原生菜单、Snap、高对比度分别仍属 DESK-03～05。截图中的模拟视频不能证明真实播放正常。

## 验证与剩余验收

**原生阻塞（2026-11-08）：** `64190dca` 已在 Flutter 3.47.8 Windows Release 验证，
导航 tooltip 可触发 AXTree 更新失败，后续页面原生树可能陈旧。源码审计与 Flutter 语义
测试通过不足以作为发布依据；先修复此边界，再继续读屏验收。复现见下述 Windows 记录。

行为测试覆盖玻璃按钮/分段、名称与状态同节点、禁用跳过、设置开关/独立 footer、色相调整、
横纵分隔条的键盘和语义动作、真实应用预览语义关闭及焦点恢复。
渲染覆盖五屏四宽度浅深色及八个强调色的组件图；具体最终门禁结果追加在
[Windows 验证记录](windows-accessibility-validation.md)。

这份源码与 Flutter 层审计不等于整个 DESK-01 验收。仍需 CI 固定 SDK 的 Windows Release
桥接/overlay/重排压力测试，以及真实 Narrator 的名称、状态、操作和朗读顺序；macOS
VoiceOver 与视频插件交互也未在本机验证。屏幕截图不能替代这些原生检查。
