你在为「Joycai Image AI Toolkits」做一次**完整的界面翻新**。这是一款 Flutter 写的桌面 / 移动应用（Windows · macOS · Linux · Android · iOS），面向画师和设计师，用 Gemini / Veo / OpenAI 等模型做批量图像生成与编辑、视频生成、提示词优化、文件管理、网页图片抓取、模型与渠道管理、用量统计。版本 3.33，功能已经成熟，**这次改的是交互和视觉，不是功能**。

## 一、四条硬约束

### 1. 主题体系原样保留

应用的配色不是一个颜色，是一套机制。设计必须**在这套机制之上**成立，而不是替换它：

- **明 / 暗 / 跟随系统** 三档。每一屏都要有亮色和暗色两版，暗色不是亮色反相，是独立调过的。
- **8 套预设主题色，每套是一对**（亮色底上一个色号、暗色底上一个色号，都是成品，原样画）。8 对色值如下，设计稿里凡是主题色，只能引用「主色」这个角色，**不能写死任何一个 hex**：

  | 预设 | 亮色 | 暗色 |
  | --- | --- | --- |
  | Blue（默认） | `#3560D5` | `#5B8DFF` |
  | BlueGrey | `#4F6C7A` | `#6F9DB5` |
  | Indigo | `#4E5FC4` | `#7A8DFF` |
  | Teal | `#00756A` | `#1FA89A` |
  | Green | `#047921` | `#4FB252` |
  | Orange | `#BF7100` | `#F59A1A` |
  | DeepPurple | `#7A4ECB` | `#A97DFF` |
  | Rose | `#CF0053` | `#FF5B83` |

- **自定义主题色**：现在设置页只有一个禁用的「自定义」占位。这次要把它设计成真的：用户挑一个颜色，系统推出亮暗一对（亮色落到白字压得住的明度，暗色提到暗底上立得住的明度），并预览。请设计选色流程、预览方式、以及「压不住白字时主色按钮改用深墨字」的形态（Orange 就是这种情况）。
- **主色只以三种形态出现**：实底（主按钮）、纯色（描边 / 开关开 / 图标 / 焦点环）、12% 底（选中态背景）＋ 底上的「主色深」文字。设计里凡是用到主色，标注属于哪一种。不要发明第四种。
- **灰阶与主色解耦**：面板、描边、正文的灰阶是一张固定的表，用户换成橙色时灰阶一个点都不动。你可以重新定义这张表（现状是一套偏冷的蓝灰，你可以换成偏暖或中性），但它必须是**固定的、不随主色移动**的。
- **状态色**（成功 / 警告 / 错误 / 信息）也不随主色移动。
- **主题必须同时在至少三个预设上验证**：Blue、Orange、Rose。任何只在蓝色上好看的东西都不算完成。每屏至少给一帧 Orange 或 Rose 的版本。

### 2. 功能一件不丢

附件的功能清单是权威。每一个动作、每一种状态、每一个对话框、每一个右键菜单项都要在新稿里找到位置。**交互方式可以彻底改**（一个对话框可以变成侧板、一个工具栏可以变成浮动胶囊、一次点击可以变成拖拽），但能做的事不能减少。每一屏交稿时附一张「清单对照」：清单里的每一项在你的稿子里对应哪个帧、哪个控件。

### 3. 三种宽度

- 手机 < 600 · 平板 600–999 · 桌面 ≥ 1000。每一屏都要三版。
- 手机没有「文件浏览器」和「图片下载器」，其它屏都有。
- 桌面和平板可以是同一套布局的不同密度，手机通常是另一种结构（单列、底部导航、sheet）。
- 现状：桌面左侧导航栏、手机底部导航 + 抽屉放次要项。你可以换导航模型，但要说明为什么。
- 桌面上应用**自绘标题栏**（36px），窗口背景是一层极光网格。Windows / Linux 上三个窗口按钮由应用自己画；macOS 上原生红绿灯在左侧、留 78px。标题栏是导航和窗口控制的一部分，纳入设计。

### 4. 引入 macOS 26 的液态玻璃（Liquid Glass）

这是本次风格的核心，也是最容易做坏的地方。请按 Apple 自己的用法来：

- **玻璃只给「控制层」，不给「内容层」。** 导航栏、工具栏、浮动操作条、分段控件、sheet、弹出菜单、任务胶囊是玻璃；图片网格、表格、表单、对话正文是不透明的内容面。玻璃浮在内容之上，内容从它后面透过来。
- **材质要有层次**：透明填充 + 背景模糊 + 饱和度提升 + 边缘的折射高光（1px 的渐变描边，亮侧亮、暗侧暗）+ 极浅的内阴影。控件在按下 / 拖动时「变得更透明、更亮」，释放时回落。分段控件的选中指示是一块在玻璃上滑动的更亮的玻璃。
- **形状用同心圆角**：外层容器圆角 = 内层控件圆角 + 内边距。浮动条在窗口角落时，它的圆角和窗口圆角同心。
- **自适应色调**：玻璃根据背后内容的明暗自动切换亮玻璃 / 暗玻璃，而不是只跟随主题。文字和图标在玻璃上用「vibrant」的半透明墨色，不用纯黑纯白。
- **主色在玻璃上的形态**：主按钮在玻璃条上是一块着色玻璃（主色 + 半透明），不是实底；请把这一形态与硬约束 1 的三种形态对齐——它归「实底」那一档，只是材质换了。
- **克制**：一个屏幕上同时可见的玻璃层不超过 3 个。列表行、卡片、输入框**不是**玻璃。

**性能上的硬指标（Flutter 实现的现实）**：

- 一次全宽背景模糊在集成显卡 4K 屏上实测 19ms / 帧，超出一整个 60fps 的预算。所以：
  - 每屏**全宽**的玻璃层最多 1 个（通常是顶部工具栏或底部导航），其余玻璃必须是小面积的浮动件。
  - 滚动内容上方的玻璃只在边缘（顶部 / 底部），不要在滚动区中间放玻璃。
- 应用有「减少视觉效果」开关。开关打开时玻璃退化成**不透明的同色面**，模糊、折射高光全部去掉，但布局、尺寸、圆角一个像素不变。每一种玻璃材质都要画出它的退化形态。
- Flutter 没有真正的折射。请把材质写成可复现的配方：模糊半径、饱和度倍数、填充色与透明度、高光描边的两端色、内阴影参数。工程侧会用 BackdropFilter + 渐变描边 + 着色器逼近。

## 二、可以推翻的东西

以下全部开放，鼓励大胆：

- 导航模型（左栏 / 顶栏 / 浮动 dock / 手机 tab bar 的组织方式）
- 工作台的空间结构：现在是「目录树 · 图库 · 配置面板」三列，六种工具（图像生成 / 视频生成 / 提示词助手 / 裁剪与缩放 / 对比器 / 蒙版编辑器）以顶部 tab 切换。可以改成画布优先、工具浮动、上下文面板按需出现，只要每种工具的所有参数都还能设。
- 面板语言：现状是通栏列 + 1px 发丝线；设置页是卡片。这次统一。
- 选择模式、批量操作条的形态
- 对话框 vs 侧板 vs sheet 的取舍
- 空状态、加载态、错误态的画法
- 动效：给一套时长 / 曲线的档位（现状有 hover 120ms · state 160ms · reveal 200ms 三档，可以重定），玻璃的形变、浮动条的出入、sheet 的弹出各用哪档。高频操作（选中、hover）不做慢动画。

## 三、不能碰的东西（设计之外）

- 界面字体不固定：系统字体 + 用户可下载的中文字体（HarmonyOS Sans / MiSans）。**设计稿用系统字体栈**，不要挑一个特定字体来撑效果。数值、日志、代码用等宽角色。
- 四种界面语言（简中 / 繁中 / 日文 / 英文），同一个标签在日文下可能是英文的两倍宽。工具栏不能靠固定像素阈值折叠——设计上给出「按顺序降级」的规则（先丢装饰，再丢标签，最后收进溢出菜单）。
- UI 文字里不用 emoji，图标用 Material Symbols。
- 圆角、间距、字号给出**阶梯**（例如 4 / 8 / 12 / 16 / 20 / 28），不要出现阶梯之外的数。

- **每屏一张清单对照**（见硬约束 2）。
