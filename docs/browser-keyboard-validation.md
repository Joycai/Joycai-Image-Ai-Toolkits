# DESK-02 浏览器键盘与跨栏焦点验证

日期：2026-11-08。PR #409；本批基线 `3e87c7e8`。

## 行为与设计

延续已有暖石灰、配对强调色和控制层玻璃。设计依据是维护中的规格、现有组件和实际
Flutter 截图；未取得历史设计服务原稿。解决文件卡不可键盘定位、列表/网格缺少独立
活动项、跨栏依赖鼠标的问题，不改写文件扫描、删除、重命名或拖放业务。

- 文件区作为一个 Tab 停靠点。普通方向键移动并单选；Shift 扩选/收缩；Ctrl/⌘
  只移动焦点；Space 切换活动文件选择；Enter 打开活动文件（媒体走预览，其他类型
  沿用系统打开）。已有 Delete/F2/复制等继续针对选区。
- 复用 `GridCursor`，按真实分组行跳过标题，列表按单列处理。路径身份跨视图切换、
  排序和换列保留；过滤/删除后回落邻项；空结果仍可进入文件区但不操作过期文件。
- `BrowserGridNavigation` 仅持有瞬态 UI 焦点和几何。滚动按实际卡片高度、分组标题、
  间距计算，能定位离屏项目，预留选择栏空间；选择集合更新仍由 `FileBrowserState` 负责。
- F6/Shift+F6 按目录树→文件区→暂存栏循环，跳过隐藏栏。各栏均可 Tab 进入，栏内
  按钮和树行继续走既有 Tab 遍历。工具栏维持普通 Tab；Ctrl/⌘+F 聚焦搜索。
  文本编辑时不响应新增按键，搜索 Esc 回到文件区。窄窗口用既有快捷键打开抽屉，
  F6 离开抽屉或关闭抽屉后回文件区；关闭有焦点的内联栏也回文件区。
- 单击、双击和右键菜单同步活动路径；预览/菜单关闭后恢复来源栏。焦点使用现有
  primary 2px 内描边，选中态保留现有外环/底色。项目语义提供名称、按钮角色、
  选中/焦点状态和打开动作；分组 sliver 的语义索引连续。
- 快捷键仍只有 `AppShortcuts` 一张表，更新英/简中/繁中/日文。源 ARB 通过文件内/
  跨模块重复键检查及四语言 key 对齐后，依次 merge 和 gen-l10n。

跨 600px 测试揭示了 shell 原有的结构变化：只在窄窗插入 `MediaQuery` 会卸载当前屏，
丢掉逻辑活动项。现在始终保留这一层，仅切换底部 dock 留白。测试覆盖完整应用从
1440 缩到 390 后继续选择原文件，并覆盖排序和移除后的回落。
首轮 390 渲染还发现底部 dock 遮住浏览器选择操作栏；浏览器 body 现在使用 shell 提供的
底部留白，确保操作栏及自动滚入的活动文件都在 dock 上方。行为测试断言两者的实际位置。

## 验证记录

环境：Windows，Flutter 3.47.9 / Dart 3.13.7。CI 固定版本仍为 3.47.8，未改 SDK。

- 首轮浏览器导航、既有快捷键和注册表测试：31 项通过。
- 修复跨断点重建后，浏览器行为与既有 rebuild scope 测试：11 项通过。
- 最终格式检查：951 文件，零格式变化；`flutter analyze`：No issues found。
- 最终浏览器行为与页面/焦点/语言渲染：57 项通过，日志未见 overflow、框架异常或
  harness exception。日志：`build/browser-render-final.log`。
- 最终完整非截图门禁：3566 项通过、6 项跳过，4 分 38 秒；日志
  `build/browser-tests-verified.log`。这是窄窗留白与六个行为场景均纳入后的完整重跑。
- 新增六个行为场景：Tab/语义/扩选/焦点移动、列表与空结果、F6 正反循环及关闭栏、
  预览和窄窗抽屉及输入保护、101 项分组虚拟滚动/排序/缩窗/移除、右键菜单与双击返回。
- 初轮渲染查看全部网格/列表 × 390/834/1024/1440 × 浅/深色，共 16 张；另查看
  四语言 390 宽快捷键说明。基线 PNG 保存在 `build/desk02-browser-baseline/`。
  正常页面、焦点样式和说明不改变原布局。390 宽属于窄桌面窗口，不代表原生手机支持。
  修复窄窗留白后重新渲染全矩阵，并再检查四张 390 焦点图及两张桌面暂存栏焦点图：
  选择操作栏已经在 dock 上方，切到暂存栏后文件选区变为中性描边，暂存栏顶边标明活动栏。

调试过程没有掩盖失败：首次尺寸测试混用了 `setSurfaceSize` 和 harness 的
`tester.view.physicalSize`，造成约束/MediaQuery 不一致和后续测试尺寸污染；改用同一
view API 后暴露并修复上述真实重建问题。一次另开 Flutter test 与截图进程争用
`sqlite3.dll` 导致启动失败，之后顺序执行测试进程。
